# GitFlow do projeto ONG Você É +

## Estratégia de versionamento

O projeto utiliza Git e GitHub para controle de versão e registro da evolução da aplicação.

Durante o desenvolvimento acadêmico, as alterações foram realizadas e registradas por meio de commits na branch principal `main`.

## Branch utilizada

- `main`: branch principal que contém a versão estável e atualmente publicada da aplicação.

## Organização dos commits

O histórico de desenvolvimento foi organizado por commits relacionados às diferentes etapas do projeto, incluindo:

- criação da estrutura inicial;
- implementação e correção das páginas HTML;
- ajustes de estilos;
- implementação da navegação SPA;
- componentes dinâmicos com JavaScript;
- persistência de dados com `localStorage`;
- correções de caminhos e acessibilidade;
- documentação do projeto;
- publicação pelo GitHub Pages.

## Fluxo adotado

O fluxo utilizado neste projeto acadêmico foi:

`alteração → teste → commit → main → GitHub Pages`

Em projetos colaborativos ou de maior porte, o fluxo pode ser ampliado com branches como `develop` e `feature/*`, além do uso de Pull Requests antes da integração com a branch principal.
